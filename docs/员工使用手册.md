> 义乌吉通集团内部即时通讯与协同办公平台，整合**即时聊天、考勤打卡、OA 审批、企业网盘（在线文档）、任务中心、组织架构、工作通知**等功能。
>
> 支持电脑浏览器、手机浏览器、平板 / iPad，并可安装为手机桌面 App（PWA），随时随地办公。

---

## 一、平台简介

平台将日常工作集中到一处，主要模块：

| 模块 | 用途 |
| --- | --- |
| 聊天室 | 私聊、群聊、语音/视频通话、语音消息、文件发送 |
| 考勤打卡 | 上下班打卡、出勤统计、考勤记录查询 |
| OA 审批 | 请假、加班、报销、出差、采购等审批流程 |
| 企业云网盘 | 文件上传/下载、分享、协作文档在线编辑 |
| 任务中心 | 任务创建、分配、看板跟踪 |
| 组织架构 | 查看部门与同事、切换企业 |
| 工作通知 | 审批、考勤、任务、协作等消息提醒 |

## 二、快速开始

### 2.1 登录

1. 电脑浏览器打开：`https://chat.first-iq.com`
2. 点击右上角「**登录**」，或直接打开聊天室后会自动跳转登录页。
3. 输入 **用户名或邮箱 + 密码**，点击登录。
   - 勾选「**记住我**」，登录状态可保持较长时间（约 7 天）。
4. **忘记密码**：登录页点击「忘记密码」→ 输入注册邮箱 → 完成滑块验证 → 打开邮箱点击重置链接设置新密码。

> 账号一般由管理员开通。若提示账号不存在，请联系管理员。

### 2.2 将应用添加到主屏幕并开启消息通知（重点推荐）

为获得类似原生 App 的体验，并保证**回到主屏幕或锁屏后仍能实时收到消息提醒**，建议安装为桌面 App 并开启通知：

**iPhone / iPad（iOS 16.4 及以上）**
1. 用 **Safari 浏览器**打开 `https://chat.first-iq.com/chat/` 并登录。
2. 点击 Safari 底部工具栏的 **分享按钮**（方框箭头图标）。
3. 选择「**添加到主屏幕**」，确认添加。
4. 从主屏幕打开该图标进入 App，首次打开聊天室时会弹出**开启通知**引导，点击「开启通知」并允许即可。
   - 也可以进入「个人设置 → 通知设置」开启桌面通知。

**Android 手机（Chrome 浏览器）**
1. 用 Chrome 打开聊天室页面并登录。
2. 点击右上角「**⋮**」菜单 →「**安装应用**」或「**添加到主屏幕**」。
3. 允许通知权限。

**电脑（Edge / Chrome）**
1. 打开聊天室页面后，点击地址栏右侧的 **安装图标**（显示器加加号）即可安装。

> - 通知权限需要**一次**授权；授权后即使把 App 切到后台、锁屏或返回主屏幕，新消息也会通过系统推送提醒你。
> - iOS 需 16.4 及以上版本才支持网页推送，请确认手机系统已更新。

### 2.3 页面通用入口

登录后多数页面右上角都有：

- **头像 / 用户菜单**：管理控制台、我的云盘、考勤打卡、OA 审批、我的任务、组织架构、个人设置、修改密码、退出登录。
- **铃铛图标（工作通知）**：查看审批、考勤、任务、协作等提醒，支持按全部/未读/已读筛选。

## 三、聊天室

### 3.1 界面介绍

- **左侧**：会话列表（最近聊天）、顶部可切换 **聊天 / 通讯录 / 群组** 三个标签并搜索。
- **右侧**：聊天窗口，顶部显示聊天对象、语音通话/视频通话/更多/主题切换按钮。
- **顶部铃铛**：工作通知。

### 3.2 新建会话

1. 点击聊天室页面「**新建聊天**」。
2. **私聊**：输入或搜索用户，点击即可发起对话。
3. **群聊**：切换到「群聊」标签，填写**群名称（≤20 字）**，勾选成员后创建。

### 3.3 发送消息

在底部输入框输入文字，点击「发送」。输入框左侧工具栏支持：

| 按钮 | 功能 | 说明 |
| --- | --- | --- |
| 🎤 语音 | 按住说话 | 按住按钮录音，松开发送；上滑取消。时长 1–60 秒 |
| 🖼 图片/视频 | 发送图片或视频 | 可多选 |
| 📎 文件 | 发送文件 | 可多选 |
| 😊 表情 | 发送表情 | |

### 3.4 语音 / 视频通话

- 在**私聊**窗口中点击聊天头部右上角的「📞 语音通话」或「🎥 视频通话」按钮发起呼叫。
- 通话中可**静音、开关摄像头、切换前后摄像头、免提/听筒、最小化、挂断**。
- 群聊暂不支持发起通话（界面会提示「请私聊」）。

### 3.5 @提及 与 @所有人

- 在输入框输入 `@` 可选择成员进行提醒，被 @ 的人会收到醒目提醒。
- 输入 `@所有人` 可提醒群内全部成员（用于通知类消息，请勿滥用）。

### 3.6 消息操作

在消息上点击右键（电脑）或长按（手机），可：

- **撤回**：发送后 **10 分钟** 内可撤回自己的消息，超时无法撤回。
- **转发**：转发到其它会话，转发的消息会带「转发消息」标记。
- **引用**：引用某条消息后回复，方便针对某条消息讨论。
- **复制 / 收藏 / 搜索**：支持聊天记录搜索。

### 3.7 会话管理

- **置顶**：将会话固定在列表顶部，方便查找。
- **免打扰**：开启后该会话新消息不再提醒。
- **删除会话**：删除聊天记录列表入口（不影响对方）。

### 3.8 发送限制速查表

| 类型 | 限制 |
| --- | --- |
| 单条文字 | ≤ 2000 字 |
| 语音消息 | 1–60 秒 |
| 图片 | 单张 ≤ 20MB |
| 视频 | 单个 ≤ 100MB |
| 文件 | 单个 ≤ 50MB |
| 语音文件 | 单个 ≤ 30MB |
| 消息撤回 | 发送后 10 分钟内 |

### 3.9 个人资料与通知设置

点击右上角头像 →「**个人设置**」：

- **头像**：点击上传，支持 JPG / PNG，≤ 2MB。
- **基本信息**：真实姓名、性别、邮箱、手机号。
- **工作信息**：部门、职位。
- **通知设置**：桌面通知、声音提醒、震动提醒。
- 另可在此「**修改密码**」（新密码 ≥ 8 位）。

## 四、考勤打卡

### 4.1 入口

点击右上角头像 →「**考勤打卡**」，或侧边栏底部入口进入。

### 4.2 打卡流程

1. 进入考勤页，「今日打卡」卡片会显示 **上班打卡 / 下班打卡** 按钮与当前状态。
2. 点击打卡按钮，浏览器会请求**定位权限**（请允许），系统记录打卡时间、定位地址与设备。
3. 打卡成功后状态更新；若当前时段无需打卡，页面会显示「该时段无需打卡」。

> **请确保手机/电脑已开启定位服务并允许网页获取位置**，否则可能打卡失败。

### 4.3 查看统计与记录

- **统计卡片**：出勤天数、上班打卡次数、下班打卡次数、迟到、早退次数。
- **记录列表**：按日期查看打卡明细（类型、时间、状态、地点、设备），支持搜索与日期筛选。
- **日历视图**：以日历方式查看每日状态（正常 / 迟到 / 缺卡 / 缺勤），不同状态颜色区分。

### 4.4 打卡规则

- 上下班打卡时间受**考勤配置**约束（由管理员按集团 / 子公司 / 部门设置）。
- 默认参考：上班打卡截止 09:00、下班打卡开始 18:00（以实际配置为准）。
- 打卡地点会在地图中显示，便于核对。

## 五、OA 审批

### 5.1 入口

点击右上角头像 →「**OA 审批**」。

### 5.2 发起审批

1. 点击「**新建审批**」，选择类型：**请假 / 加班 / 报销 / 出差 / 采购 / 招聘需求 / 其他**。
2. 按类型填写信息：
   - **通用**：部门（必填）、标题（必填）、内容、开始/结束时间（系统自动计算时长）、金额等。
   - **招聘需求**：额外填写岗位、编制数、职责、任职要求、薪资范围、到岗日期等。
3. 选择**审批方式**（或签 / 会签）与**审批模式**（并行 / 顺序），系统会自动生成**审批链预览**。
4. 如需抄送，添加**抄送人员或部门**；需要时可上传**附件**（≤10 个，单个 ≤10MB，支持常见图片/文档/压缩包格式）。
5. 点击「**提交审批**」，或先「**存草稿**」稍后继续。

### 5.3 处理审批

- 在「**待审批**」列表查看需要你处理的事项。
- 打开详情可查看完整申请内容与审批链：
  - **通过**：如果配置要求签名，需**手写签名**后提交。
  - **驳回**：需填写驳回原因。
  - 还可选择**暂缓**（稍后处理）或**办理中**。

### 5.4 我的审批状态

通过顶部状态筛选查看：**全部 / 待审批 / 已通过 / 已驳回 / 暂缓 / 办理中 / 已撤回 / 草稿**，随时跟踪进度。

## 六、企业云网盘与在线文档

### 6.1 入口

点击右上角头像 →「**我的云盘**」或顶部「云网盘」。

### 6.2 文件上传与管理

- **上传**：点击上传，可拖拽或选择文件；大文件自动**分片上传**（支持断点续传）。
- **管理**：右键或选中文件可 **打开 / 重命名 / 移动 / 删除 / 分享 / 评论 / 星标收藏**。
- **侧边栏**：全部文件 / 星标 / 我的分享 / 分享给我 / 协作文档 / 共享文件夹 / 回收站 / 数据统计 / 操作日志。

### 6.3 分享文件

1. 选择文件 →「分享」。
2. 选择分享方式：**公开链接** 或 **提取码**（≤5 位），可设置**有效期**与**最多下载次数**。
3. 生成链接或二维码发送给同事。

### 6.4 协作文档（在线编辑）

1. 在「协作文档」中新建文档，选择**协作者**，可选发送协作通知。
2. 点击文档在 **OnlyOffice 在线编辑器** 中打开，可直接编辑 **文字 / 表格 / 演示文稿**，修改自动保存。
3. 文档详情支持 **协作者管理、文档设置、版本历史**（可查看/恢复历史版本）。

### 6.5 共享文件夹与回收站

- **共享文件夹**：与成员共享，权限分**只读 / 读写 / 管理**。
- **回收站**：误删的文件可在回收站找回。

### 6.6 上传限制

| 类型 | 限制 |
| --- | --- |
| 普通文件 | 单个 ≤ 50MB |
| 图片 | 单张 ≤ 20MB |
| 视频 | 单个 ≤ 100MB |
| 音频 | 单个 ≤ 30MB |
| 分片大文件 | 单文件上限 500MB |

## 七、任务中心

### 7.1 入口

点击右上角头像 →「**我的任务**」。

### 7.2 界面与视图

- 左侧筛选：**我的任务 / 我创建的 / 今日到期 / 已完成**（带数量角标）。
- 右上角切换**列表 / 看板**视图。

### 7.3 新建与处理任务

1. 点击「**新建任务**」：填写标题（必填）、描述、**执行人**、**截止日期**、**优先级**（低/中/高/紧急）、状态。
2. 点击任务可打开详情，**内联编辑**标题 / 状态 / 优先级 / 描述，并查看或新增**评论**。
3. **看板视图**：任务分为 **待处理 / 进行中 / 已完成** 三列，可**拖拽**卡片改变状态。
4. 若任务来自聊天消息，可一键「**查看原消息**」「**在线编辑文档**」或「**保存到云盘**」。

## 八、组织架构

### 8.1 查看部门与同事

- 点击右上角头像 →「组织架构」，进入组织树。
- 左侧为部门树，右侧显示当前部门成员，成员按 **负责人 → 副负责人 → 成员** 金字塔排列。
- 顶部可**搜索部门 / 成员**。

### 8.2 切换企业

- 若你同时属于多个企业（集团/子公司），可在聊天室或组织架构**顶部企业下拉**中一键切换当前企业。
- 切换后，聊天、审批、网盘等数据均按当前企业展示。

> 部门/成员信息有误、需要新增部门或调整负责人时，请联系企业管理员。

## 九、工作通知

- 所有主页面**顶部铃铛**集中展示工作通知，按类型区分图标颜色：审批（蓝）、考勤（绿）、任务（橙）、协作（紫）、系统（灰）。
- 支持：**全部 / 未读 / 已读** 筛选、单条标记已读、「**全部标为已读**」、点击「查看详情」跳转对应页面。
- 审批、任务、协作等事件会通过**系统通知**实时提醒（需已授权通知权限，见 2.2）。

## 十、常见问题（FAQ）

**1. 收不到消息推送 / 回到主屏幕没有提醒？**
请确认：① 已按 2.2 节添加到主屏幕并从 App 图标打开；② 已允许通知权限（个人设置 → 通知设置 → 桌面通知）；③ iOS 系统需 16.4+。若仍不行，联系管理员检查后台推送配置。

**2. 忘记密码怎么办？**
登录页点「忘记密码」，用注册邮箱接收重置链接。收不到邮件请检查垃圾箱或联系管理员。

**3. 上传文件提示太大？**
请对照各模块的**大小限制**（聊天：图片 20MB/视频 100MB/文件 50MB；网盘：普通 50MB、分片上限 500MB；审批附件：单个 10MB）。压缩后再试，大文件请走网盘分片上传。

**4. 语音消息录不了 / 发不出去？**
请检查麦克风权限，并确认录音时长在 1–60 秒之间；部分浏览器需点击一次页面后才能录音。

**5. 如何切换企业？**
聊天室或组织架构页**顶部企业下拉**一键切换。

**6. 考勤打不了卡？**
请开启定位权限并允许浏览器获取位置；确认当前在考勤配置的打卡时间内；如仍异常，截图打卡页联系管理员。

**7. 审批提交错了可以撤回吗？**
在「我的审批」中找到该审批，若仍在流程中可尝试**撤回**或「重新编辑」；已处理完的流程请联系审批人/管理员。

**8. 在线文档无法编辑？**
确认该文档你拥有编辑权限；若为共享文件夹，检查是否被授予**读写**以上权限。多人同时编辑时请保持网络稳定。

**9. 如何修改头像 / 密码？**
右上角头像 →「个人设置」，可上传头像、修改资料；「修改密码」设置新密码（≥8 位）。

**10. 需要新增账号 / 部门 / 调整考勤或审批配置？**
请联系企业管理员处理。
