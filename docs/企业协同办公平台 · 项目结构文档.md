# 企业聊天室（企联云）项目结构文档

> 基于 Django + Channels 的企业级即时通讯与协同办公平台

---

## 目录结构概览

```
company_chat/                          # 项目根目录
├── manage.py                          # Django 管理入口
├── company_chat/                      # Django 主配置
├── accounts/                          # 用户认证模块（多企业/部门/日志）
├── chat/                              # 即时通讯模块
├── cloud/                             # 企业网盘模块（含 OnlyOffice 协作/操作权限）
├── oa/                                # OA办公模块（考勤+审批+补贴+物资+工作日历+水印/打印）
├── tasks/                             # 任务管理模块
├── org/                               # 组织架构模块（多企业隔离）
├── utils/                             # 工具库（加密/OCR/权限/头像压缩等）
├── templates/                         # 前端模板
├── static/                            # 静态资源
├── media/                             # 用户上传文件
└── .env                               # 环境变量
```

## 二、用户认证模块 `accounts/`

### 核心功能

## 三、即时通讯模块 `chat/`

### 核心功能
- 私聊/群聊消息收发
- WebSocket 实时通信（Django Channels，AES/SM4 加密）
- 消息类型：文本、图片、语音、视频、文件、表情、任务卡片、审批卡片、工作总结卡片
- 消息引用（回复）、撤回
- 聊天室管理（创建/加入/退出/解散/置顶/免打扰）
- 文件上传与同步到网盘
- 音视频通话（WebRTC）
- 版本更新检测、未读消息计数、桌面/移动端推送（Web Push/FCM）
- 截图、图片预览（移动端左右滑动/双指缩放）

### 关键文件

| 文件 | 说明 |
|------|------|
| `models.py` | `ChatRoom`、`Message`、`MessageFile`、`FileUpload`、`ChatRoomMember` |
| `views.py` | 聊天室 CRUD、消息 CRUD、文件上传、版本信息、管理员接口 |
| `consumers_encrypt.py` | WebSocket 消费者（加密通信） |
| `urls.py` | `/api/chat/` 路由 |
| `routing.py` | WebSocket 路由 |
| `middleware.py` | WebSocket JWT 认证中间件 |
| `tasks.py` | Celery 任务 |
| `pagination.py` | 分页配置 |

### WebSocket 事件

| 事件类型 | 说明 |
|---------|------|
| `chat.message` / `chat.image` / `chat.voice` / `chat.file` / `chat.location` / `chat.video` / `chat.emoji` / `chat.task_card` / `chat.quote` | 各类消息 |
| `call.*` | 音视频通话信令 |
| `typing` | 正在输入 |
| `message_read` | 消息已读 |
| `approval.*` | 审批私聊卡片 |

## 四、企业网盘模块 `cloud/`

### 核心功能
- 文件/文件夹 CRUD（多级目录）、回收站、星标、批量操作
- 文件上传（分片/断点续传/秒传）
- 文件预览（图片、视频、文档）
- 文件分享（公开链接+密码+二维码+二维码下载）

- 协作文档、共享文件夹（成员+权限+私聊通知）
- 操作日志、数据统计
- 系统配置管理（存储/上传/分享/协同/系统设置）
- **企业操作权限**：允许打印/允许文件下载/允许公开分享（全局 + 用户自定义，覆盖全局）
- **企业水印**：管理控制台配置显性/隐性水印，逐页开关

### 关键文件

| `routing.py` | WebSocket 路由 |
| `share_urls.py` | 公共分享页面路由 |
| `pagination.py` | 分页配置 |

### 企业操作权限（cloud + utils）

| 权限 | 说明 |
|------|------|
| `allow_print` | 允许打印（默认关闭；控制 OA 审批/考勤/补贴等打印） |
| `allow_download` | 允许文件下载（`system.download_enabled` 全局开关 + 用户自定义覆盖） |
| `allow_public_share` | 允许公开分享 |
| 全局 vs 用户 | 全局存 `CloudSystemConfig.cloud_operation_permissions`；用户自定义存 `UserCloudOperationPermission`（覆盖全局） |

## 五、OA办公模块 `oa/`

### 核心功能
- **考勤打卡**：上班/下班打卡、白班/夜班、补卡、个人考勤配置、位置记录、月度统计
- **OA审批**：审批流程（顺序/并行、或签/会签）、动态审批类型、阈值审批、票据回传、自定义收款方式、物资需求单/领用单；详情「上一条/下一条」连续审批、待我审批/我已审批过滤
- **每日工作总结**：员工上传工作数据（图片/文档/表格）+ 当日总结，按职位生成提示词，Celery 异步流式调用火山方舟大模型分析（deepseek 式打字输出 + markdown 渲染）；部门负责人看本部门、超管看全员（部门/日期/搜索过滤）；支持范围批量分析、导出（Markdown/Word/PDF→本地或网盘）、私聊分享、打印预览；工作日历全局完成情况图表
- **普惠补贴**：发票申领/核验/支付、钱包/提现、二维码扫描验证、OCR/百度验真
- **工作日历**：跨模块工作汇总、每日通知、时间线/审批效率图表、每日工作总结完成情况图表（超管）
- **企业水印/打印**：显性+隐性水印逐页生效；打印留痕（`PrintLog`）+ 打印水印 + 允许打印权限
- **工作通知**：审批/考勤/补贴/任务/每日汇总/总结分享，WebSocket 实时推送

### 关键文件

| 文件 | 说明 |
|------|------|
| `models.py` | `AttendanceRecord`、`AttendanceConfig`、`UserAttendanceConfig`、`ApprovalType`、`ApprovalRequest`、`ApprovalNode`、`ApprovalAssignee`、`ApprovalLog`、`ApprovalCarbonCopy`、`ApprovalDeptConfig`、`CustomPaymentMethod`、`WorkNotification`、`DailyDigestConfig`、`SubsidyApplication`、`SubsidyPayment`、`SubsidyWithdrawal`、`SubsidyWallet`、`SubsidyInvoiceVerifyRecord`、`SubsidyConfig`、`MaterialItem`、`MaterialRequirement(+Item)`、`MaterialRequisition(+Item)`、`DocumentSequence`、`WatermarkConfig`、`PrintLog`、**`DailyWorkSummary`**（每日总结）、**`WorkSummaryRangeAnalysis`**（范围分析）、**`WorkSummaryConfig`**（大模型配置/开关） |
| `views.py` | 考勤 API、审批 API、补贴/财务 API、物资 API、工作日历 API（含全员总结完成统计）、每日总结 API（上传/提交/团队/范围分析/配置/分享/导出PDF）、通知 API、水印/打印接口 |
| `serializers.py` | 序列化器 |
| `urls.py` | `/api/oa/` 路由 |
| `type_utils.py` | 内置审批类型 schema（含物资需求单/领用单） |
| `material_utils.py` | 物资单据号生成、需求单/领用单联动、台账 |
| `tasks.py` | Celery 任务：每日通知、每日总结大模型流式分析（`analyze_work_summary_task` / `analyze_work_summary_range_task`）、工作汇总（含昨日总结完成统计） |

### 审批流程模式

| 模式 | 说明 |
|------|------|
| `parallel` | 并行审批（所有节点同时审批） |
| `sequential` | 顺序审批（节点依次审批） |

### 审批签署方式

| 方式 | 说明 |
|------|------|
| `orsign` | 或签（一人通过即可） |
| `countersign` | 会签（需全部通过） |

### 内置审批类型（可自定义扩展）

| 类型 | 说明 |
|------|------|
| `leave` | 请假 |
| `overtime` | 加班 |
| `expense` | 报销 |
| `trip` | 出差 |
| `purchase` | 采购 |
| `material_requirement` | 物资需求单 |
| `material_requisition` | 物资领用单 |
| `other` | 其他 |

## 十四、API 路由汇总

### 认证 `/api/auth/`
- `POST /register/`、`POST /login/`、`POST /token/refresh/`、`GET /me/`、`POST /change-password/`、`POST /reset-password/`、`POST /upload-avatar/`（头像上传压缩+原图）、`PUT /profile/`（资料更新）

### 聊天 `/api/chat/`
- 聊天室/消息/文件/未读/版本（`GET /version/`）/管理员接口

### 网盘 `/api/cloud/`
- 文件/文件夹/上传分片/分享/共享文件夹/协作文档/回收站/操作日志/统计
- `/api/cloud/settings/*`：分类/配置列表/更新/重置/清缓存/系统信息/导出、OnlyOffice 协同配置、协同编辑用户权限、**操作权限**（`operation-permissions` / `user-operation-permissions` / `users-for-operation-permission` / `effective-permission`）
- 下载（文件/文件夹/版本）按「允许下载」权限放行

### OA `/api/oa/`
- 考勤：打卡/补卡/白夜班/个人配置/日历统计/导出
- 审批：列表/详情/通过/驳回/暂缓/撤销/草稿/票据回传/私聊提醒/自定义收款方式/审批类型/审批配置/物资
- 补贴：发票上传/OCR/二维码扫描/核验/支付/提现/钱包/导出
- 工作日历：`/work-calendar/` 汇总、`day/` 当日、`stats/` 统计、`approval-efficiency/` 审批效率、`approval-leaderboard/` 排行榜、`work-summary-stats/` 全员总结完成统计（超管）、`digest-config/` 每日通知、`digest-send/` 手动发送
- 每日总结：`/work-summary/` 列表/提交、`upload/` 文件上传、`all/` 团队列表、`members/` 成员搜索、`config/` 模型配置（超管）、`range/` 批量分析、`<pk>/` 详情/删除、`<pk>/analyze/` 重新分析、`<pk>/share/` 私聊分享、`<pk>/export-pdf/` 导出真实 PDF
- 通知：`/notifications/`、`unread-count/`、`mark-all-read/`

### 系统 `/api/system/`
- `/watermark-config/` — 企业水印配置（GET 渲染 / POST 超管保存）
- `/print-log/` — 打印操作留痕（记录页面/对象/条数/IP/时间）

### 任务 `/api/tasks/`、组织 `/api/org/`
- 任务 CRUD / 企业-部门-成员-汇报管理
