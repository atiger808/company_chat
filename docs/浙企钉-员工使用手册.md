> 义乌吉通集团内部即时通讯与协同办公平台，整合**即时聊天、考勤打卡、OA 审批、企业网盘（在线文档）、任务中心、组织架构、工作通知**等功能。
>
> 支持电脑浏览器、手机浏览器、平板 / iPad，并可安装为手机桌面 App（PWA），随时随地办公。

## 一、平台简介

平台将日常工作集中到一处，主要模块：

| 模块 | 用途 |
| --- | --- |
| 聊天室 | 私聊、群聊、群公告、语音/视频通话、语音消息、文件发送 |
| 考勤打卡 | 上下班打卡（含指定区域打卡、白班/夜班、补卡）、出勤统计、考勤记录查询 |
| OA 审批 | 请假、加班、报销、出差、采购、招聘需求、物资需求/领用/入库等审批流程 |
| 普惠补贴 | 员工消费发票申领、财务核验、财务支付、补贴发放、钱包提现 |
| 物资管理 | 物资需求单、领用单、入库单与物品库库存台账 |
| 工作日历 | 跨模块工作汇总、每日待办、当日工作记录一览、活跃度图表、每日总结完成情况（超管） |
| 每日工作总结 | 上传当日工作数据（图片/文档/表格）+ 总结，大模型按职位流式分析并给出优化建议 |
| 集团公告 | 集团层面的公告发布（富文本）、按范围投放、评论、点赞、自动归档 |
| 报表与数据分析 | OA 审批与普惠补贴的业务统计与导出（默认隐藏，超管开启并授权） |
| 企业云网盘 | 文件上传/下载、分享、跨目录搜索、协作文档在线编辑 |
| 任务中心 | 任务创建、分配、看板跟踪 |
| 组织架构 | 查看部门与同事、切换企业 |
| 工作通知 | 审批、考勤、任务、协作等消息提醒（支持右上角弹窗提醒） |
| 企业知识库 | 在线文档：左侧目录树 + 右侧内容 + 锚点 + 全文搜索（即本手册的在线版） |

## 二、快速开始

### 2.1 登录

1. 电脑浏览器打开：`https://chat.first-iq.com`
2. 点击右上角「**登录**」，或直接打开聊天室后会自动跳转登录页。
3. 输入 **用户名或邮箱 + 密码**，点击登录。
   - 勾选「**记住我**」，登录状态可保持较长时间（约 7 天）。
4. **忘记密码**：登录页点击「忘记密码」→ 输入注册邮箱 → 完成滑块验证 → 打开邮箱点击重置链接设置新密码。

> 账号一般由管理员开通。若提示账号不存在，请联系管理员。

### 2.2 将应用添加到主屏幕并开启消息通知（重点推荐）

为获得类似原生 App 的体验，并保证**回到主屏幕或锁屏后仍能实时收到消息提醒**，建议安装为桌面 App 并开启通知：

**iPhone / iPad（iOS 16.4 及以上）**
1. 用 **Safari 浏览器**打开 `https://chat.first-iq.com/chat/` 并登录。
2. 点击 Safari 底部工具栏的 **分享按钮**（方框箭头图标）。
3. 选择「**添加到主屏幕**」，确认添加。
4. 从主屏幕打开该图标进入 App，首次打开聊天室时会弹出**开启通知**引导，点击「开启通知」并允许即可。
   - 也可以进入「个人设置 → 通知设置」开启桌面通知。

**Android 手机（Chrome 浏览器）**
1. 用 Chrome 打开聊天室页面并登录。
2. 点击右上角「**⋮**」菜单 →「**安装应用**」或「**添加到主屏幕**」。
3. 允许通知权限。

**电脑（Edge / Chrome）**
1. 打开聊天室页面后，点击地址栏右侧的 **安装图标**（显示器加加号）即可安装。

> - 通知权限需要**一次**授权；授权后即使把 App 切到后台、锁屏或返回主屏幕，新消息也会通过系统推送提醒你。
> - iOS 需 16.4 及以上版本才支持网页推送，请确认手机系统已更新。

### 2.3 页面通用入口

登录后多数页面右上角都有：

- **头像 / 用户菜单**：工作日历、考勤打卡、OA 审批、普惠补贴、每日工作总结、集团公告、我的云盘、我的任务、组织架构、**企业知识库**、个人设置、修改密码、退出登录。
- **铃铛图标（工作通知）**：查看审批、考勤、任务、协作、每日汇总等提醒，支持按全部/未读/已读筛选；集团公告等重要通知还支持**右上角弹窗提醒**（见 11.4）。
- **顶部导航下拉**：在普惠补贴相关页面显示「**财务服务**」下拉（补贴配置 / 财务核验 / 财务支付），在 OA 审批页显示「**审批服务**」下拉（类型管理 / 审批配置），入口按你的角色权限显示或隐藏。
- **企业知识库**：直接访问 `https://chat.first-iq.com/docs/`，可查阅本手册、项目结构文档与接口文档（支持全文搜索与锚点分享），详见第十七章。

## 三、聊天室

### 3.1 界面介绍

- **左侧**：会话列表（最近聊天）、顶部可切换 **聊天 / 通讯录 / 群组** 三个标签并搜索。
- **右侧**：聊天窗口，顶部显示聊天对象、语音通话/视频通话/更多/主题切换按钮。
- **顶部铃铛**：工作通知。

### 3.2 新建会话

1. 点击聊天室页面「**新建聊天**」。
2. **私聊**：输入或搜索用户，点击即可发起对话。
3. **群聊**：切换到「群聊」标签，填写**群名称（≤20 字）**，勾选成员后创建。

### 3.3 发送消息

在底部输入框输入文字，点击「发送」。输入框左侧工具栏支持：

| 按钮 | 功能 | 说明 |
| --- | --- | --- |
| 🎤 语音 | 按住说话 | 按住按钮录音，松开发送；上滑取消。时长 1–60 秒 |
| 🖼 图片/视频 | 发送图片或视频 | 可多选 |
| 📎 文件 | 发送文件 | 可多选 |
| ✂ 截图 | 截图发送 | 默认为**整屏截图**（选择框默认整屏，可直接拖拽框选区域；不框选则发送整屏），可在管理控制台切换为区域截图；移动端不显示该按钮 |
| 😊 表情 | 发送表情 | |

### 3.4 语音 / 视频通话

- 在**私聊**窗口中点击聊天头部右上角的「📞 语音通话」或「🎥 视频通话」按钮发起呼叫。
- 通话中可**静音、开关摄像头、切换前后摄像头、免提/听筒、最小化、挂断**。
- 群聊暂不支持发起通话（界面会提示「请私聊」）。

### 3.5 @提及 与 @所有人

- 在输入框输入 `@` 可选择成员进行提醒，被 @ 的人会收到醒目提醒。
- 输入 `@所有人` 可提醒群内全部成员（用于通知类消息，请勿滥用）。

### 3.6 消息操作

在消息上点击右键（电脑）或长按（手机），可：

- **撤回**：发送后 **10 分钟** 内可撤回自己的消息，超时无法撤回。
- **转发**：转发到其它会话，转发的消息会带「转发消息」标记。
- **引用**：引用某条消息后回复，方便针对某条消息讨论。
- **复制 / 收藏 / 搜索**：支持聊天记录搜索。

### 3.7 会话管理

- **置顶**：将会话固定在列表顶部，方便查找。**置顶只对操作者本人生效**，不会影响同一聊天室的其他成员。
- **免打扰**：开启后该会话新消息不再提醒（桌面通知、提示音、震动一并静音）。**同样只对操作者本人生效**。
- **删除会话**：删除聊天记录列表入口（不影响对方）。
- 会话列表最后一条消息前会显示提示标记：`[@所有人]` / `[有人@我]`（红字闪烁）、`[群公告]`（发布群公告时生成的公告消息）、`[草稿]`。

### 3.8 发送限制速查表

| 类型 | 限制 |
| --- | --- |
| 单条文字 | ≤ 2000 字 |
| 语音消息 | 1–60 秒 |
| 图片 | 单张 ≤ 20MB |
| 视频 | 单个 ≤ 100MB |
| 文件 | 单个 ≤ 50MB |
| 语音文件 | 单个 ≤ 30MB |
| 消息撤回 | 发送后 10 分钟内 |

### 3.9 个人资料与通知设置

点击右上角头像 →「**个人设置**」：

- **头像**：点击上传，支持 JPG / PNG，≤ 2MB。
- **基本信息**：真实姓名、性别、邮箱、手机号。
- **工作信息**：部门、职位。
- **通知设置**：桌面通知、声音提醒、震动提醒。三个开关**即时生效**——开启「桌面通知」会申请浏览器通知权限并订阅推送（关闭则退订），声音与震动开关改动后立刻生效；当前聊天室处于免打扰时，三者都不会提醒。

### 3.10 群公告

群主与**群管理员**可以给群聊发布公告（其他成员只读）：

- **未读入口**：你所在的群有**未读群公告**时，该群聊天消息**顶部会固定显示「群公告」入口**，点击查看详情即自动标记已读，入口随之消失。
- **发布即发消息**：发布或修改群公告时，会同时在群里发一条以公告为内容的**群公告消息**（带「📣 群公告」气泡与「查看群公告详情」入口），左侧会话列表该群最后一条消息前会显示 `[群公告]`（红字闪烁，与 @ 提示同款）。
- **修改后重新提醒**：公告内容更新后，已读回执会被清空，所有成员（除发布人）会重新看到未读入口。
- **入口位置**：除聊天顶部外，群聊管理弹窗（`群聊管理`）内也有「群公告」入口，群主/群管理员可在此发布、修改或删除。

> 群公告由群主或群管理员维护；普通成员只能查看。

### 3.11 群成员与用户资料

- 点击群聊头部进入群管理/群成员列表：成员以**宫格形式每行 5 个**展示头像与昵称（含职位），**点击成员头像**可直接打开该成员的**用户信息**模态框（查看部门、职位、联系方式、在线状态等）；关闭用户信息后会回到群成员弹窗，不会把群成员弹窗一起关掉。
- **群主**可在成员项上「**设为 / 取消群管理员**」或「**移除成员**」（移动端按钮为图标小圆钮）。
- 成员较多时可用弹窗内搜索框按昵称筛选。

## 四、考勤打卡

### 4.1 入口

点击右上角头像 →「**考勤打卡**」，或侧边栏底部入口进入。

### 4.2 打卡流程

1. 进入考勤页，「今日打卡」卡片会显示 **上班打卡 / 下班打卡** 按钮与当前状态。
2. 点击打卡按钮，浏览器会请求**定位权限**（请允许），系统记录打卡时间、定位地址与设备。
3. 打卡成功后状态更新；若当前时段无需打卡，页面会显示「该时段无需打卡」。

> **请确保手机/电脑已开启定位服务并允许网页获取位置**，否则可能打卡失败。

### 4.3 查看统计与记录

- **统计卡片**：出勤天数、上班打卡次数、下班打卡次数、迟到、早退次数。
- **记录列表**：按日期查看打卡明细（类型、时间、状态、地点、设备），支持搜索与日期筛选。
- **日历视图**：以日历方式查看每日状态（正常 / 迟到 / 缺卡 / 缺勤 / 请假 / 休息），不同状态颜色区分（请假为蓝色、休息为灰色）。

### 4.4 打卡规则

- 上下班打卡时间受**考勤配置**约束（由管理员按集团 / 子公司 / 部门设置）。
- 默认参考：上班打卡截止 09:00、下班打卡开始 18:00（以实际配置为准）。
- 打卡地点会在地图中显示，便于核对。
- **未打卡提醒**：系统按你参照的**考勤配置**上下班时间判断漏打卡；**下班卡**需当日时间已过 23 点才判定为漏打，避免白天误报。
- **休息日或请假不提醒**：星期日 / 法定节假日，以及处于**已批准请假**日期内，不提示未打卡；考勤日历中分别标记为「休息」「请假」。

### 4.5 指定区域打卡

管理员可按集团 / 子公司 / 部门**在地图上圈定多个打卡范围**（可设置中心点与半径）：

- 若你被要求**指定区域打卡**，打卡页会显示地图与你的位置、打卡点标识，并校验你是否处于允许范围内；不在范围内将无法打卡并给出提示（请开启定位权限）。
- 地图支持**拖动与缩放**（手机端可用手指拖动/双指缩放），并提供**全屏**查看与底部打卡点标识；未被要求区域打卡的员工不会加载地图，不影响打卡。

### 4.6 白班 / 夜班与个人考勤配置

- **班次**：考勤配置支持**白班**（默认上班 09:00 / 下班 18:00）与**夜班**（上班 20:00 / 下班次日 06:00，跨天计算）；夜班员工的「待下班」状态与下班卡判定会自动顺延到次日。
- **打卡次数**：可配置每日需要打几次卡（例如只打上班、或上下班各一次）；不需要打卡的时段页面会提示「该时段无需打卡」。
- **个人考勤配置**：管理员可为**指定成员**单独配置考勤（部门负责人 / 超管可在考勤页的「个人考勤配置」中选择成员并保存），优先级为**个人配置 > 部门 > 子公司 > 集团默认**，优先级越高越先生效。
- **补卡**：漏打卡时可在考勤页对指定日期发起**补卡申请**（按配置开启），补充上班 / 下班卡时间与说明。

## 五、OA 审批

### 5.1 入口

点击右上角头像 →「**OA 审批**」。

### 5.2 发起审批

1. 点击「**新建审批**」，选择类型：**请假 / 加班 / 报销 / 出差 / 采购 / 招聘需求 / 其他**。
2. 按类型填写信息：
   - **通用**：部门（必填）、标题（必填）、内容、开始/结束时间（系统自动计算时长）、金额等。
   - **招聘需求**：额外填写岗位、编制数、职责、任职要求、薪资范围、到岗日期等。
3. 审批方式固定为**会签**（需全部通过）、审批模式固定为**顺序审批**（依次审批），无需手动选择；系统会自动生成**审批链预览**（当金额 / 天数超过配置阈值时会自动追加**阈值审批**环节）。
4. 如需抄送，添加**抄送人员或部门**；需要时可上传**附件**（≤10 个，单个 ≤10MB，支持常见图片/文档/压缩包格式）。
5. 点击「**提交审批**」，或先「**存草稿**」稍后继续。

### 5.3 处理审批

- 在「**待审批**」列表查看需要你处理的事项。
- 打开详情可查看完整申请内容与审批链：
  - **通过**：如果配置要求签名，需**手写签名**后提交；通过时可 **@ 提及**成员（可附审批意见），被提及的人会收到一张直达该审批的**私聊卡片**与工作通知。
  - **驳回**：需填写驳回原因。
  - 还可选择**暂缓**（稍后处理）或**办理中**。

### 5.4 我的审批状态

- 通过顶部状态筛选查看：**全部 / 待我审批 / 我已审批 / 我发起的 / 抄送我的 / 待审批 / 已通过 / 已驳回 / 暂缓 / 办理中 / 已撤回 / 草稿**，随时跟踪进度。
- **待我审批**：只看等待本人处理的事项；**我已审批**：只看本人已处理（通过 / 驳回 / 暂缓 / 办理中）的事项，便于批量连续处理。
- 审批详情顶部有「**上一条 / 下一条**」切换：处理完成后详情不会关闭，会刷新为下一条待办，审批人可**连续审批**。
- 列表与详情均显示「**审批请求 ID**」，该 ID 是审批的唯一编号，可复制给同事用于定位问题。

### 5.5 发票字段（报销 / 采购等）

涉及票据的审批类型（如报销、采购）支持**发票字段**：

- **上传**：支持图片与 **PDF**（PDF 会自动转换为图片便于预览），可一次上传多张、可折叠收起；数量上限由配置决定。
- **自动识别**：上传后自动 OCR 识别发票号码、类型、金额、开票日期、购买方 / 销售方、开票人等并回填，识别不到的字段可手动修改。
- **扫码与验真**：可**扫描发票二维码**并与识别结果对比辅助判假；开启发票验真时可一键调用验真接口。
- **移动端适配**：发票信息在手机上同样可正常查看与编辑，点击发票/图片可全屏预览（点击返回）。

### 5.6 票据回传

审批**通过之后**，若该类型开启了票据回传，申请人 / 审批人可在审批详情中**回传票据**（发票或其他凭证）：

- 回传的发票会同步写入表单的发票数据，可继续查看、扫码与验真。
- 回传涉及**数量上限**与**回传时限**（由配置决定，默认 24 小时）；**审批通过后不可删除该审批**，以保证留痕。
- 票据回传的类型与配置的启停**仅超级管理员**可调整。

### 5.7 审批归档与审计复盘

- **自动治理**：超级管理员可配置**审批生命周期**——审批完成满设定天数后自动**归档**、更长天数后自动**清理**；归档的审批仍可查询，不再参与日常待办。
- **归档筛选**：在「我的审批」中可按「归档」状态筛选查看历史审批。
- **审计复盘**（超管）：提供独立的审计复盘视图，按类型 / 状态 / 金额 / 人员等维度回看审批流转情况，便于管理与合规追溯。

## 六、财务服务 · 员工消费普惠补贴

### 6.1 入口

点击右上角头像 →「**普惠补贴**」。

### 6.2 提交申领

1. 点击「**上传发票**」选择票据（图片或 PDF，单个 ≤ 50MB，一次最多 10 张）。
2. 上传后系统**自动识别**发票内容（发票号码、类型、金额、开票日期、购买方 / 销售方、开票人等），自动填充表单并自动选择发票类型；识别不出的字段可手动修改。
3. 确认无误后点击「**提交申领**」，等待财务核验。

### 6.3 我的申领与钱包

- 查看申领状态：**待核验 / 已通过 / 已驳回**；被驳回的申领可「**重新申领**」修改后再次提交，或「**删除**」该条申领。
- 核验通过后补贴**自动转入我的钱包**；在「我的钱包」查看余额 / 累计入账 / 累计提现，可发起**提现**（金额须 ≥ 最小提现额度且 ≤ 余额），提交后由财务支付人员处理，并可查看我的提现记录。
- 「补贴发放记录」展示实际支付流水，支持一键刷新。

### 6.4 申领核验（财务核验人员 / 超级管理员）

- 在「**财务核验**」页（顶部「财务服务」下拉进入）查看待核验申领，支持搜索、筛选、**导出 Excel**、打印。
- 打开详情可核对发票原件与识别字段；支持「**二维码扫描**」解码发票二维码并与识别结果对比，辅助判断发票真伪；开启发票验真时可一键「**发票验真**」。
- 核验人员可**修改发票类型**（专用 / 普通），系统自动同步重算补贴比例与金额。
- 点击「**通过**」弹出确认框，补贴金额**自动转入申请人钱包**；或「**驳回**」并填写原因。
- 通过 / 驳回均通过工作通知告知申请人。

### 6.5 提现支付（财务支付人员 / 超级管理员）

- 用户在钱包发起提现后，财务支付人员在「**财务支付**」页查看**待支付**提现，支持搜索、筛选、导出 / 打印。
- 打开「支付」弹窗可核对收款信息与收款码、查看该用户提现记录；上传**付款凭证（付款截图）**后确认支付，或**驳回**（金额自动退回用户钱包）。
- 已支付 / 已驳回的提现可查看详情。

### 6.6 补贴配置（仅超级管理员 / 财务核验 / 财务支付人员）

- 支持集团 / 子公司 / 部门三级配置：补贴比例（专用 / 普通发票）、是否开启、财务核验人员、财务支付人员、提现最小额度、默认 OCR 版本、发票验真开关、发票抬头、税率阈值等。
- **税率阈值**（默认 6%）：识别出的税率 ≥ 阈值自动判定为**增值税专用发票**，否则为普通发票。
- 补贴配置入口位于普惠补贴 / 财务核验 / 财务支付页顶部「财务服务」下拉，仅对应角色可见、可操作。

## 七、物资管理

物资相关操作以**审批单据**的形式流转（在 OA 审批页进行），并通过「物资管理」查看台账与库存。

### 7.1 三类单据

| 单据 | 用途 | 说明 |
| --- | --- | --- |
| 物资需求单 | 提出需要采购的物资 | 填写物资名称、数量、预估单价等；单据号自动生成 |
| 物资入库单 | 需求物资到货后入库 | 关联需求单，填写**实际入库明细**与金额；需求单详情可查看每张入库单的**实际金额** |
| 物资领用单 | 从物品库领用物资 | 可先选「**可领用物资**」再领用，无需事先知道需求单号；支持同一需求单**分多次领用**（按剩余可领数量控制） |

### 7.2 常用流程

1. **发起需求**：审批页 → 新建审批 → 选择「物资需求单」→ 填写物资明细并提交（进入审批流）。
2. **到货入库**：需求单通过后，发起「物资入库单」并**关联该需求单**，填写实际入库数量与金额；同一需求单不可重复发起入库单。入库单通过后会**通知需求单发起人**，并可在通知中一键「去入库」。
3. **领用**：新建「物资领用单」，从「可领用物资」中选择（或按物资查找需求单）→ 明细单价与金额按**入库单价**自动计算 → 提交审批；领用明细会按剩余可领数量校验。

### 7.3 物品库与库存台账

- 「物资管理」中可查看**物品库**（主数据/库存）与**库存流水**；物品库由入库单自动建档。
- 入库、领用、库存调整都会写入**库存流水**，可追溯每一次变动。
- 普通员工可查看物品库（只读）；管理类操作按角色权限开放。

## 十二、每日工作总结

### 12.1 入口

点击右上角头像 →「**每日工作总结**」，或各页面顶部导航 / 聊天室下拉菜单进入。

### 12.2 提交今日工作总结

1. 页面默认显示**今日日期**；选择工作总结日期（默认今天）。
2. 上传**工作数据文件**（图片 / 文档 / 表格，可多选）：
   - **图片**显示为缩略图，点击可全屏预览（支持左右滑动 / 键盘切换）；
   - **文档 / 表格 / 其他文件**点击自动保存到我的网盘「每日工作总结」文件夹，可编辑文档（Word / Excel / PPT / PDF）保存后自动打开**在线编辑**；
   - 也可点「**从我的网盘选择**」直接引用网盘里已有的文件（无需重新上传，系统会把文件复制一份到本模块，保证后续查看与在线编辑不受网盘权限影响）。
3. 填写**当日工作总结**（今天完成的工作、遇到的问题、解决思路方法、达到的效果、明日计划等）。
4. 点击「**提交并分析**」，系统按你的**职位**生成专属提示词，调用**火山方舟大模型**进行流式分析——分析结果会以 **deepseek 式打字效果**逐字输出并渲染 markdown（标题 / 列表 / 加粗 / 代码块等），完成后显示**分析完成时间**。

> 若管理员停用了模型分析，提交的总结仅保存、不再调用大模型，页面顶部会有提示。

### 12.3 我的总结记录

- 每条记录展示：日期、职位、分析状态（待分析 / 分析中 / 已完成 / 分析失败 / 已停用）与**分析完成时间**。
- 可对记录执行：**详情**（查看提示词与完整分析）、**重新分析**、**导出**、**分享**、**编辑**（载入表单再次提交，生成新的记录，原记录保留）；仅超级管理员可**删除**。
- 若今日总结未提交，页面顶部会提示「今日工作总结未完成，请及时提交」。

### 12.4 导出与打印

- 详情页 / 列表点「**导出**」：可选 **Markdown / Word / PDF**，保存到**本地**或**我的网盘**。
- 点「**打印**」打开带「返回 / 关闭」按钮的打印预览页（移动端可正常关闭），点击「打印」仅打印预览内容。

### 12.5 分享到私聊

点「**分享**」，搜索并选择用户，系统以「每日工作总结」**私聊卡片**发送给对方，对方点击直达总结详情，同时发送工作通知提醒。

### 12.6 团队总结与批量分析（部门负责人 / 超级管理员）

- **团队总结**：部门负责人仅能查看**本部门成员**的总结，超级管理员可查看**全员**总结，支持**部门 / 日期 / 搜索员工**过滤。
- **批量分析**：选择员工与日期范围（默认近 30 天），系统汇总该时间段内总结，按职位生成提示词调用大模型进行**阶段性综合分析**，结果流式展示，可查看喂给大模型的提示词。
- **模型设置**（仅超管）：可选火山方舟推荐大模型或**自定义模型 ID**，并可「**启用 / 停用模型分析**」。

### 12.7 点赞与评论

你可以在其他成员的每日工作总结上**点赞**与**评论**（按权限可见的范围内），互动会通过工作通知实时提醒对方，互动次数也会计入工作日历的活跃度。

### 12.8 使用限制与模型配置

- **调用限额**：为控制大模型成本，系统对分析请求设有**限额与重试**机制（按配置）；达到限额时提交会提示稍后再试。
- **数据脱敏**：送往大模型的提示词会做**脱敏**处理，避免敏感信息外泄。
- **模型配置**（仅超管）：可切换模型、设置每日调用上限、是否启用灰度（只对部分成员开启）等。
- **记录不可删除**：每日总结**不提供删除**，用于归档留痕；需要修正请「编辑」后重新提交（生成新记录，原记录保留）。

### 13.3 每日通知

- 超级管理员可在工作日历页点「**每日通知配置**」，设置：启用开关、每日发送时间（HH:MM）、自动 / 手动发送。
- **自动发送**：系统按设定时间每天向员工推送「今日工作汇总」，包含待处理审批 / 待核验发票 / 待支付提现 / 待处理任务数，今日是否漏打上班 / 下班卡，以及**昨日工作总结是否完成**（未完成会提示「昨日工作总结未完成，请及时补充」），点击直达工作日历。
- **手动发送**：关闭自动后，管理员可随时点「**立即发送每日汇总**」推送。

---

### 13.4 活跃度与成员关系

- **活跃度**：工作日历记录的每一次操作（审批 / 补贴 / 提现 / 任务 / 文档 / 组织 / 每日总结 / 公告 / 打卡等）都会累计为活跃度；**各操作的权重可由超管配置**，便于按企业实际口径衡量投入。
- **统计图表**：提供时间线与审批效率图表，按部门聚合；超管可查看**成员关系活跃度**（含关系网络图）与部门/岗位维度的对比。
- **每日总结完成情况**：见 13.2 末（超管可看全局提交率与缺勤明细）。
- **公告操作汇总**：集团公告的发布、浏览量、评论、点赞会汇总进工作日历的活跃度与事件列表，可点击跳转到对应公告。

## 十四、集团公告

集团公告面向**整个集团 / 指定范围**发布，是集团层面的官方通知渠道（与群聊里的「群公告」不同）。

### 14.1 入口与权限

- **入口**：右上角头像 →「**集团公告**」，或聊天室侧边栏底部 / 顶部导航的「集团公告」。
- **发布权限**：只有**超级管理员**与**超级管理员在管理控制台授权的用户**可以看到「发布公告」按钮并发布；其他用户只能查看。
- **编辑/删除权限**：仅**公告发布人本人**可编辑、发布、删除自己的公告。

### 14.2 发布公告（富文本编辑器）

「发布公告」支持丰富的排版（编辑器工具栏）：

| 分组 | 能力 |
| --- | --- |
| 字体 | 微软雅黑 / 宋体 / 黑体 / 楷体 / 苹方 / Arial / Georgia / Courier New |
| 字号 | 12 ~ 36px |
| 颜色 | 字体颜色、背景高亮（20 色调色板 + 自定义取色，支持清除） |
| 段落 | 正文 / 标题 1~4 / 引用 / 代码块 |
| 基础 | 加粗、斜体、下划线、删除线、有序/无序列表、减少/增加缩进、对齐（左/中/右/两端）、分割线、清除格式、撤销/重做 |
| 插入 | 链接、图片（上传或 URL）、视频（URL）、表格、附件链接 |
| 便捷 | **直接粘贴截图**即可插入图片；粘贴网页/Word 内容会自动清理脚本等危险内容 |

> 编辑完成后可先「**预览**」查看发布后的展示效果；可「**存草稿**」稍后再发布。

### 14.3 发布范围

可选：**集团全员** / **指定子公司** / **指定部门** / **指定成员**（多选）。范围内的成员可在集团公告页看到该公告。

### 14.4 查看、评论与点赞

- 列表展示标题、发布范围、发布人、浏览量、评论数与点赞数；点击进入详情。
- **评论**：发布时可设置是否开启评论，以及评论方式——**公开**（范围成员可见）或**匿名**（仅本人与发布人可见）；评论支持**配图、表情**与**二级回复**。
- **点赞**：可对公告点赞/取消点赞（点赞计入工作日历活跃度）。
- **通知**：公告发布后会向范围内成员发送工作通知；若管理员开启了公告类型的**弹窗提醒**，还会在页面右上角弹出（见 11.4）。

### 14.5 自动归档

- 公告发布满**自动归档期限**（默认 1 天，可由超管在管理控制台配置为 1~365 天）后**自动归档**。
- **归档后任何人（含发布人与超级管理员）都不能编辑或删除**，只能查看；归档公告会显示「已归档」标记并隐藏编辑/发布/删除按钮。

## 十五、报表与数据分析

报表用于从整体上查看审批与补贴的业务数据，**默认隐藏**，需要超级管理员在管理控制台开启并授权。

### 15.1 入口与权限

- 超级管理员进入「管理控制台 → **报表权限**」，分别开启「**OA 审批报表**」与「**普惠补贴报表**」（两个开关相互独立），并可配置**哪些成员**可以查看/使用。
- 开启并授权后，OA 审批页与普惠补贴页（含财务核验页、财务支付页）顶部会出现「**报表与数据分析**」入口；未开启或未授权时入口不显示，直接访问接口也会被拒绝。

### 15.2 OA 审批报表

- 业务统计：各审批类型的**笔数与金额**（合并展示）、审批通过 / 驳回 / 待处理等状态分布、金额字段统计。
- 支持按**时间范围**与**用户**筛选；可按部门维度对比。
- 展示审批效率（处理时长）等指标。

### 15.3 普惠补贴报表

- 核验与提现统计：通过核验的申领笔数与金额、补贴发放、提现笔数与金额（「通过核验的开票金额」的笔数与「通过核验的补贴」口径一致）。
- 支持按**时间范围**与**用户**筛选、用户排行（补贴 / 提现）。

### 15.4 导出与打印

- 报表支持**导出 Excel / PDF**：文件名会自动带上日期范围与筛选条件，可选择保存到**本地**或**我的网盘**（默认目录为报表）。大报表导出请耐心等待。
- 报表模态框支持**打印**与**整页导出 PDF**（底部有关闭按钮），移动端同样可用。

## 十六、管理控制台

管理控制台面向**管理员 / 超级管理员**（普通用户不可访问），入口在右上角头像菜单的「**管理控制台**」。

### 16.1 权限说明

- **超级管理员**：可管理全部企业、全部部门的用户，并使用全部管理功能。
- **普通管理员**：**只能查看和管理自己所在部门（本部门）的用户**——其它部门、其它企业的用户一律不可见；用户的新建 / 编辑 / 删除 / 重置密码 / 启用停用 / 批量删除 / 离职交接等操作同样被限制在本部门内。新建用户时**部门强制为本部门**、用户类型强制为「普通用户」，并自动加入企业与组织架构。

### 16.2 用户管理

- **筛选**：支持按企业 / 部门筛选（普通管理员的部门筛选固定为「本部门」且不可切换）、按用户名/姓名/邮箱/电话**搜索**，以及按**状态**筛选（全部状态 / **仅启用** / **仅禁用**）。
- **新建用户**：填写用户名、密码、邮箱、真实姓名、性别、手机号、部门、职位、用户类型（超管可选），并可**分配好友**（选中的人会出现在该用户的通讯录中）；超管还可选择所属企业与组织架构部门。
- **编辑 / 重置密码**：可修改资料、重置为指定密码（默认 `123456`，建议让用户首次登录后修改）。
- **启用 / 禁用**：禁用后（一般指员工离职）该用户**无法登录及使用任何系统服务**；禁用用户的「离职交接」按钮会以橙色高亮提示可交接。
- **离职一键交接**：把离职者名下的**网盘文件 / 文件夹 / 相关分享**平滑交接给接替者（原文件归属改为接替者）；接替者可用姓名 / 账号 / 职位 / 部门关键字搜索选择，选好后确认交接，交接完成后建议再禁用该用户。
- **批量删除**（超管）：勾选多个用户后一次性删除。

### 16.3 聊天室管理（超管）

查看全部聊天室（群聊 / 私聊）、成员数、最后消息与更新时间，可进入某聊天室的**历史消息**并导出；群聊的历史消息中，审批卡片 / 工作总结卡片 / 协作邀请卡片会以**卡片化**方式展示，点击可直达对应详情。

### 16.4 数据统计（超管）

用户总数 / 在线用户 / 今日活跃 / 今日消息 / 聊天室总数 / 存储使用等概览卡，以及用户趋势、消息趋势、消息类型分布、活跃时段、活跃用户 TOP 10、热门聊天室 TOP 5、部门用户分布等图表（支持时间范围切换与刷新）。

### 16.5 系统设置（超管）

按分类维护平台配置项（基础设置 / 聊天设置 / 文件设置 / 语音设置 / 安全设置 / 通知设置 / 高级设置），支持搜索、修改、重置为默认、导出配置、清除缓存、发送测试通知等；「系统信息」面板可查看运行环境信息。

### 16.6 水印设置（超管）

统一配置**企业水印**：全局开启、公司名称 / 附加文字、字体大小与颜色、样式（常规 / 加粗 / 斜体）、旋转角度、透明度、位置（整页平铺 / 居中 / 四角）、形状（纯文字 / 印章）、**隐性水印**（含姓名/部门/职位/IP/设备，用于溯源）；并可**逐页开关**（审批 / 考勤 / 补贴 / 每日工作总结等）与配置**打印时是否添加水印**。打印操作会记录**打印留痕**（页面 / 对象 / 条数 / IP / 时间）。

### 16.7 通知弹窗 / 公告设置 / 报表权限（超管）

- **通知弹窗**：配置哪些类型的通知会在页面右上角**弹出提醒**（默认仅「集团公告」），以及弹窗停留时长（默认 10 秒）。
- **公告设置**：配置**可发布集团公告的成员**（按姓名/账号/职位/部门搜索多选）与**公告自动归档期限**（默认 1 天，1~365 天）。
- **报表权限**：分别开启 OA 审批 / 普惠补贴的「报表与数据分析」，并授权可查看的成员（见第十五章）。

### 16.8 日志

- **登录日志**（超管）：记录用户、IP、登录类型、浏览器、系统、位置与时间。
- **操作日志**（所有管理员）：记录操作人、所属模块、请求路由、方法、IP、状态与时间，便于追溯关键操作（含离职交接、审批通过/驳回、公告发布等带参数接口）。

## 十七、企业知识库（在线文档）

企业知识库把平台文档集中到一处，支持**左侧目录树 + 右侧内容 + 锚点 + 全文搜索**，可直接作为企业内部培训与查阅入口。

### 17.1 入口

- 浏览器打开 `https://chat.first-iq.com/docs/`，或从聊天室头像菜单的「**企业知识库**」进入。
- 需要**登录**才能查看内容（未登录会跳转登录页）。

### 17.2 界面与操作

- **左侧目录树**：按分组展示文档（平台使用 / 研发与运维 / 第三方接口等），点击文档右侧会展开其**章节**（H2/H3）与折叠箭头，点击章节即跳转到对应位置；当前所在章节会高亮。
- **右侧内容**：正文支持表格、代码块、引用、列表等；每个标题右侧有 `#` 锚点，**点击即可复制该章节的链接**（`.../docs/#/文档/章节`），便于在聊天或审批里精确指路。
- **顶部搜索**：输入关键字（如「群公告」「发票」）即可**跨全部文档全文搜索**，结果显示文档分组、章节标题与**命中片段（高亮）**，点击直达对应章节；`Ctrl + K` 可快速聚焦搜索框，`Esc` 清空。
- **本页目录**：标题较多的文档会在正文顶部生成「本页目录」，便于快速跳转。
- **打印**：右上角「打印」按钮可**只打印当前文档正文**（自动隐藏目录与工具栏），也可用于「另存为 PDF」。
- **其它**：右上角可切换**深色 / 浅色主题**；手机端目录收起为抽屉，点击左上角按钮展开。

### 17.3 收录内容

| 分组 | 文档 |
| --- | --- |
| 平台使用 | 员工使用手册（本文） |
| 研发与运维 | 项目结构文档、项目文件自动备份功能 |
| 第三方接口 | 百度增值税发票验真接口文档 |

### 17.4 新增 / 维护文档

知识库文档直接取自项目仓库的 `docs/` 目录（Markdown）：把 `.md` 文件放入 `docs/`，并在 `company_chat/views.py` 的 `KNOWLEDGE_DOCS` 中登记（分组、标题、说明、文件名），部署后即出现在知识库中——**无需改数据库**。文档内的 Markdown 语法（标题 / 表格 / 列表 / 代码块 / 引用 / 链接）都会被正确渲染，标题会自动生成锚点。

## 十八、常见问题（FAQ）

**1. 收不到消息推送 / 回到主屏幕没有提醒？**
请确认：① 已按 2.2 节添加到主屏幕并从 App 图标打开；② 已允许通知权限（个人设置 → 通知设置 → 桌面通知）；③ iOS 系统需 16.4+。若仍不行，联系管理员检查后台推送配置。

**2. 忘记密码怎么办？**
登录页点「忘记密码」，用注册邮箱接收重置链接。收不到邮件请检查垃圾箱或联系管理员。

**3. 上传文件提示太大？**
请对照各模块的**大小限制**（聊天：图片 20MB/视频 100MB/文件 50MB；网盘：普通 50MB、分片上限 500MB；审批附件：单个 10MB）。压缩后再试，大文件请走网盘分片上传。

**4. 语音消息录不了 / 发不出去？**
请检查麦克风权限，并确认录音时长在 1–60 秒之间；部分浏览器需点击一次页面后才能录音。

**5. 如何切换企业？**
聊天室或组织架构页**顶部企业下拉**一键切换。

**6. 考勤打不了卡？**
请开启定位权限并允许浏览器获取位置；确认当前在考勤配置的打卡时间内；如仍异常，截图打卡页联系管理员。

**7. 审批提交错了可以撤回吗？**
在「我的审批」中找到该审批，若仍在流程中可尝试**撤回**或「重新编辑」；已处理完的流程请联系审批人/管理员。

**8. 在线文档无法编辑？**
确认该文档你拥有编辑权限；若为共享文件夹，检查是否被授予**读写**以上权限。多人同时编辑时请保持网络稳定。

**9. 如何修改头像 / 密码？**
右上角头像 →「个人设置」，可上传头像、修改资料；「修改密码」设置新密码（≥8 位）。

**10. 群公告看不到 / 发不了？**
顶部入口只在**有未读群公告**时显示，看完即隐藏（可在群聊管理弹窗里再次查看）；发布群公告需要你是**群主或群管理员**，普通成员只能查看。

**11. 置顶或免打扰后，别人也被置顶/免打扰了？**
不会。置顶与免打扰都是**按人**的偏好，只对操作者本人生效，不会影响同一聊天室的其他成员。若发现异常请刷新页面。

**12. 切换聊天室时提示「消息加载失败」？**
这是网络抖动导致的瞬时失败，系统会自动重试；重试仍失败时消息区会出现「**重新加载**」按钮，点击即可重新拉取当前聊天室的历史消息，无需刷新整页。

**13. 集团公告为什么不能编辑/删除了？**
公告发布满设定期限后会**自动归档**，归档后任何人（包括发布人与超级管理员）都不能编辑或删除，只能查看。请在此之前完成修改。

**14. 找不到「报表与数据分析」入口？**
该功能**默认隐藏**，需要超级管理员在管理控制台「报表权限」中开启并把你加入授权名单，之后入口才会出现在 OA 审批 / 普惠补贴页面顶部。

**15. 知识库打不开 / 搜索不到内容？**
知识库需要登录后访问 `https://chat.first-iq.com/docs/`；搜索支持跨全部文档，若搜不到说明文档中确实没有该关键字，可换个说法或联系管理员补充文档。

**16. 需要新增账号 / 部门 / 调整考勤或审批配置？**
请联系企业管理员处理；**集团公告发布权限、报表权限、公告归档期限**等由超级管理员在管理控制台配置。
