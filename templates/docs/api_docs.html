企联云开放 API

欢迎使用企联云开发者文档。通过我们的 RESTful API 和 WebSocket 接口，您可以轻松将企业级即时通讯与网盘能力集成到您的内部 OA、ERP 或 CRM 系统中。

基础 URL: 所有 API 请求的基础路径为 https://api.qilian.com/v1 (私有化部署请替换为您自己的域名)。

身份认证

企联云 API 使用 Bearer Token 进行身份验证。您需要在每个请求的 HTTP Header 中包含您的 Access Token。

HTTP Header 示例
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

聊天室管理

POST 创建群聊

创建一个全新的群组聊天室，并邀请指定成员加入。

cURL 请求示例
curl -X POST https://api.qilian.com/v1/chat/rooms/ \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "room_type": "group",
    "name": "产品研发部",
    "member_ids": [101, 102, 105]
  }'

GET 获取用户聊天列表

获取当前认证用户参与的所有聊天室列表（包含未读消息数）。

响应示例 (200 OK)
{
  "count": 2,
  "results": [
    {
      "id": 45,
      "name": "产品研发部",
      "room_type": "group",
      "unread_count": 3,
      "last_message": {
        "content": "今天的代码评审定在下午3点",
        "timestamp": "2026-06-16T14:30:00Z"
      }
    }
  ]
}

文件与网盘

POST 上传文件

支持分片上传与 MD5 秒传去重。最大支持 500MB 单文件（可在系统设置中调整）。

JavaScript (Fetch) 示例
const formData = new FormData();
formData.append('file', document.querySelector('#fileInput').files[0]);
formData.append('file_md5', 'd41d8cd98f00b204e9800998ecf8427e'); // 可选，用于秒传

fetch('https://api.qilian.com/v1/chat/upload/', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_ACCESS_TOKEN' },
  body: formData
}).then(res => res.json()).then(data => console.log(data.file_url));
